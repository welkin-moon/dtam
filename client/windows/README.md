# DTAM Windows client

Optional Windows launcher for the online DTAM build.

- Requires Microsoft Edge and .NET 8 Desktop Runtime.
- Double-click `DTAM.exe` to open `https://d1.lunarlab.uk/` in Edge app mode.
- `DTAM.exe 45` opens room 45 directly.
- The web version remains the canonical client; installing this launcher is optional.
